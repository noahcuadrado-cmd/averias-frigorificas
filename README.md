# Curso Gas B — Producción con PROMPT MAESTRO v9

Repositorio de trabajo para montar el curso completo (fases 0 → 5) a partir del
temario de origen, siguiendo el **PROMPT MAESTRO v9**.

## Estructura

- `_materiales_origen/` → **aquí van los PDF/DOCX del temario** (la fuente).
- `ESTADO - qué está hecho.md` → panel de control (qué está hecho, qué falta, plan).

## Cómo aportar los materiales

Sube los PDF/DOCX del temario a la carpeta `_materiales_origen/` (arrastrar y
soltar desde GitHub, o `git add` desde tu ordenador). En cuanto estén, se
arranca la **FASE 0** (organización en carpetas + reparto temas→vídeos).
