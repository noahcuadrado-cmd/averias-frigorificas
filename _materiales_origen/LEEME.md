# Carpeta de materiales de origen

Suelta aquí los **PDF/DOCX del temario** (los ~14 PDF del curso Gas B).

Puedes subirlos todos a la vez:
- **Por la web de GitHub**: entra en esta carpeta → botón **Add file → Upload files**
  → arrastra los 14 PDF → **Commit changes**.
- **Desde tu ordenador**: copia los PDF aquí y `git add _materiales_origen && git commit && git push`.

Una vez estén, se arranca la FASE 0.
